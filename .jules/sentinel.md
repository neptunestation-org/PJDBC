## 2026-06-17 - ReadonlyDriver Regex Bypasses
**Vulnerability:** SQL security filters using `^\s*` anchors can be bypassed by leading block comments `/* ... */` or line comments `-- ...`. Additionally, DML operations can be hidden within Common Table Expressions (CTEs) using `WITH ... AS (INSERT/UPDATE/DELETE ...)`.
**Learning:** Simple whitespace-only anchors at the start of a string are insufficient for SQL parsing because most databases allow comments anywhere whitespace is allowed, including before the first keyword. Regex-based security filters must explicitly account for all comment styles.
**Prevention:** Use a robust `PREFIX` regex that matches any combination of whitespace and comments: `^(?:\s|/\*.*?\*/|--.*?(?:\n|$))*`. Always use `Pattern.DOTALL` to ensure multi-line comments are handled. For CTEs, specifically check the content of `AS (...)` clauses for blocked keywords.
