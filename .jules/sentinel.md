## 2026-07-29 - [UserMapDriver Properties NullPointerException Fix]
**Vulnerability:** When a connection was established through `UserMapDriver` with a `null` properties object (`info`), the driver attempted to retrieve the user name via `info.getProperty("user")`, triggering an unhandled `NullPointerException`. This runtime exception could expose internal implementation stack traces to callers.
**Learning:** Checking nested properties under a properties container requires verifying that the container itself is non-null. Standard proxy routing logic in other drivers often delegates `info` directly to the underlying driver, but custom security mapping/authentication drivers like `UserMapDriver` need defensive null validation prior to querying configurations.
**Prevention:** Always validate driver connection properties explicitly before reading properties from the `Properties` block, ensuring that any missing/empty/null configurations raise a clean and generic `SQLException("PJDBC: Authentication failed")` to prevent user enumeration or stack trace leaks.
