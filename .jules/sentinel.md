## 2026-05-01 - ResultSet Getter Bypass and Alias Vulnerability in DataMaskingDriver
**Vulnerability:** DataMaskingDriver failed to mask data when using complex types (Blobs, Clobs, Arrays, etc.) or when using SQL aliasing (e.g., `SELECT secret AS alias`).
**Learning:** `AbstractResultSet`'s `transformValue` hook only covers common types like `String`, `int`, and generic `getObject`. Many specialized JDBC getters bypass this hook, leading to data leaks if not explicitly overridden in the security driver. Furthermore, checking only the `columnLabel` in getters allows bypasses via SQL aliasing.
**Prevention:** Security-focused proxy drivers must explicitly override the entire `ResultSet` interface to ensure a "fail-secure" posture. All label-based getters should be refactored to resolve the column index via `findColumn(label)` and then delegate to their corresponding index-based getters where the primary security logic resides. This ensures consistent policy enforcement regardless of how the data is requested.
