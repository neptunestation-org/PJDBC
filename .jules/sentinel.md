## 2026-02-18 - [DataMaskingDriver Bypass and Info Leak]
**Vulnerability:** `DataMaskingDriver` was vulnerable to masking bypasses via column aliasing (e.g., `SELECT secret AS alias`) and leaked sensitive data through alternative JDBC accessors like `getBlob()`, `getClob()`, `getArray()`, and `getObject(..., Class<T>)`.
**Learning:** Proxy-based security drivers must ensure total coverage of the delegated interface. Any method not explicitly handled that returns sensitive data represents a potential bypass. Relying on user-provided column labels for security checks is unsafe as they can be easily changed via SQL aliases; resolving to the underlying column index is necessary for robust enforcement.
**Prevention:** Use `findColumn()` to resolve labels to indices at the start of every security-sensitive method. Throw `SQLException` ("fail-secure") for any data type or method that cannot be safely transformed or masked, rather than allowing it to pass through unhandled.
